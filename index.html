Tentang Program

HARMONI (Healing and Resilience Narrative Inclusion) merupakan program PKM-PM yang berfokus pada pemulihan emosional dan penguatan daya tahan psikologis remaja fatherless berbasis komunitas.

Program ini dirancang untuk membantu remaja yang kehilangan peran ayah akibat meninggal dunia, perceraian, atau keterpisahan jangka panjang, melalui pendekatan naratif, partisipatif, dan berbasis aktivitas.

Website PKM-PM HARMONI dikembangkan sebagai media pendukung pelaksanaan program yang berfungsi untuk dokumentasi kegiatan, transparansi proses pengabdian, serta sarana diseminasi model penguatan resiliensi remaja fatherless berbasis komunitas.

Mitra Program

Panti Yatim Manarul Ulum terletak di Jl. Raya Cirahong, Pawindan, Kec. Ciamis, Kabupaten Ciamis, Jawa Barat 46215.

Mitra program berada dalam kondisi fatherless dengan mayoritas anak asuh merupakan anak yatim, piatu, serta anak yang dititipkan oleh satu atau kedua orang tua. Kondisi ini berdampak pada aspek emosional, identitas diri, dan ketahanan psikologis remaja.

Dampak Program

Peningkatan Kepercayaan Diri

Remaja menunjukkan peningkatan keberanian dalam mengekspresikan perasaan dan pendapat secara sehat.

Regulasi Emosi Lebih Adaptif

Remaja mulai mengenali emosi diri dan menggunakan strategi coping positif melalui pendekatan naratif.

Partisipasi Sosial Meningkat

Keterlibatan remaja dalam aktivitas kelompok dan proyek aksi komunitas meningkat secara signifikan.

Keberlanjutan Program

Program HARMONI dirancang tidak berhenti pada satu siklus pelaksanaan. Melalui penyusunan buku pedoman mitra, media edukasi, serta penguatan kapasitas komunitas panti, model intervensi ini dapat direplikasi dan dilanjutkan secara mandiri.

Website ini berperan sebagai media dokumentasi berkelanjutan dan ruang pembelajaran terbuka bagi mitra dan pemangku kepentingan.
